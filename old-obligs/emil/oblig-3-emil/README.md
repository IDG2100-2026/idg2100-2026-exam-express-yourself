# Spanish Dice Poker

## Getting Started:

### 1. Clone the repository

```bash
git clone https://github.com/IDG2100-2026/idg2100-2026-oblig3-frontend-emilllarsen.git
```

### 2. Install dependencies
The project has separate folders for backend and frontend. Install dependencies for booth:

```bash
First open the terminal
#Backend
cd backend
npm install

#Frontend
cd ../frontend
npm install
```

### 3. Environment variables
The `.env` files for booth backend and frontend is included in the repository for convenience purposes of grading



### 4. Run the Application

Open two terminals. One for backend and one for frontend

**Terminal 1  Backend:**

```bash
cd backend
npm run dev
```

**Terminal 2  Frontend**
```bash
cd frontend
npm run dev
```


The frontend will be available at `http://localhost:5173`and the backend API at `http://localhost:8080/api`
